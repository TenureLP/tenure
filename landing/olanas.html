Tenure × Olanas

Let an agent value
your position. 0.003 USDG a call.

The valuation behind the Tenure app is listed on Olanas, the API launchpad on Robinhood Chain. An agent running the Olanas Payments MCP finds it, pays for it and reads the answer, with no account, no API key and no wallet prompt per call.

See the listing on Olanas Read the integration guide

What an agent gets

One call. Everything a deal needs.

Give it a Uniswap v4 position id on Robinhood Chain. It answers with what the position is worth, what it really earns, and terms it could be sold and leased back on. It only reads: nothing is signed and nothing is sent on the agent's behalf.

HOLDS

What is in it

The pool, both tokens, the range, whether it is in range, the exact amount of each token and the fees not yet collected, valued in USDG.

EARNS

What it really makes

Fees per day and fee APR, measured from the pool's own accumulators over a day of chain history, with the source and a confidence flag. Not a model.

RAISES

What it could be sold for

Indicative sale price, buyback and rent for a lease of the length the agent asks for, ready to list on the Tenure vault as they are, or to negotiate from.

How it works

From install to answer.

01 · INSTALL

The Olanas Payments MCP

A local MCP server and companion wallet by Olanas. It creates a key on your own machine, encrypts it locally, and registers itself with Claude, Codex, Gemini or any MCP client. Their README has the one command.

Olanas Payments MCP →

02 · BOUND IT

A spending session you set

Fund the wallet, then enable a session in the companion: a per-call cap, a total budget and an expiry. Nothing is spent until you do, and nothing beyond what you allow.

03 · ASK

“Value position 3093793”

The agent searches the launchpad, finds Tenure position valuation, pays 0.003 USDG through the Olanas gateway and gets the valuation back.

What we do with Olanas

A service on their launchpad, and code in their repository.

We list on it

  • Tenure position valuation was one of the first services published on the launchpad.
  • It ships with its OpenAPI document, which Olanas republishes pointing at their gateway.
  • Its gateway answers a standard x402 version 2 challenge: onchain-tx, eip155:4663, 0.003 USDG.

We contribute to it

  • Olanas is open source. We read the code we depend on.
  • When we find something worth fixing, we send the fix upstream as a pull request, under the Tenure name.
  • Anything sensitive goes to their team privately first, never into a public thread.
